BANK HEIST: SAFE CODE  (version 5)
Version 5 adds the MEMORISE THE SAFE CODE screen: after question 10 the full code is shown for
5 seconds (gold, then red and pulsing for the last 3), then it disappears and the keypad opens by itself.
(Version 4 settings kept: 5 lives, 30-second timer, each code digit is shown twice.)

HOW TO PLAY
1. Unzip this folder.
2. Open index.html in Chrome, Edge or Firefox.
3. Click anywhere (or press a key) - the background music starts on your first click,
   because browsers block sound until you interact with the page.

FILES
index.html                 the page structure
style.css                  the design
game.js                    the game logic + question banks (4 themes x 25 questions)
audio/background-music.mp3 homepage + game music (loops)
audio/correct.mp3          correct answer sound
audio/wrong.mp3            wrong answer / timeout sound
audio/unlock.mp3           safe unlocking sound
audio/gameover.mp3         game over sound
bank-heist-full-game.html  the SAME game in ONE file (CSS, JS and audio embedded)

USE YOUR OWN MUSIC
Replace audio/background-music.mp3 with your own mp3 (same name), or change the
paths in AUDIO_FILES near the top of the settings section in game.js.
If an audio file is missing, the game falls back to built-in synthesised sounds.

The music and sound effects were generated for this project, so there are no copyright issues.
